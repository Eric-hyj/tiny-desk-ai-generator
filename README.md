# Tiny Desk AI Generator

[Visit Tiny Desk AI Generator](https://tinydeskaigenerator.video/)

Create a personalized AI desk-concert video from one shared photo or two portraits. This repository contains an independently written product guide, not the proprietary website or template source code.

## Make a video

1. Open the [studio](https://tinydeskaigenerator.video/) and sign in with Google.
2. Upload photos you are authorized to use. Choose a desk concert, pet concert or photo effect.
3. Select the duration, aspect ratio and resolution; review the displayed credit cost.
4. Submit the task, follow its status and download the completed MP4 from My Videos.

The studio supports 5–15 seconds at 480p or 720p. Concert modes request newly generated audio; photo effects are silent. It creates a new performance rather than reproducing an original recording frame for frame. Download completed videos within the 14-day access window.
